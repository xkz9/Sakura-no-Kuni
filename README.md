# Japanese City Builder

## Vision

A relaxing yet deep medieval Japanese city-building game inspired by Kingdoms and Castles.

Players lead a clan through generations, building villages, castles and towns while surviving changing seasons, managing families, navigating politics and expanding their influence.

The settlement grows outward from a fortified clan manor — the heart of Sakura no Kuni — which upgrades over time into a great castle.

Each new game begins in a unique procedurally generated world, created from a seed so the same map can be recreated.

## Core Features

- Castle progression (clan manor to great castle)
- Procedural world generation (seed-based maps)
- Grid-based building
- Four seasons
- Family simulation
- Politics
- AI clans
- Trade
- Research
- Dynamic events

## Art Style

Low-poly stylized medieval Japan.

## Engine

Unity 6 (URP)

## Coding Principles

- Modular systems
- Easy to read
- Beginner friendly
- Expandable
