# Japanese City Builder

## Vision

A relaxing yet deep medieval Japanese city-building game inspired by Kingdoms and Castles.

Players lead a clan through generations, building villages, castles and towns while surviving changing seasons, managing families, navigating politics and expanding their influence.

## Core Features

- Grid-based building
- Procedural maps
- Four seasons
- Family simulation
- Politics
- AI clans
- Trade
- Research
- Dynamic events

## Art Style

Low-poly stylized medieval Japan.

## Engine

Unity 6 (URP)

## Coding Principles

- Modular systems
- Easy to read
- Beginner friendly
- Expandable
